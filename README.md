# Guerreiros das Cápsulas

Jogo de aventura pixelado feito pela família Alex, Grasi, Artur e Gabriel: crie seu guerreiro, capture e evolua monstrinhos, nade nos rios, decore sua casa e junte as 7 Esferas para chamar o Dragão Sagrado.

**Jogar:** https://alexpernaoficial.github.io/guerreiros-das-capsulas/

- Funciona no computador (teclado) e no celular (joystick na tela).
- Cada aparelho guarda o próprio jogo.
- No **Mundo da Família**, todos jogam na mesma ilha pela internet, se veem, trocam monstrinhos e batalham.
- Para uma sala só da família, use um código: `.../guerreiros-das-capsulas/?sala=seucodigo`.

## Como funciona

- `index.html`: o jogo inteiro, num arquivo só.
- O online usa o Firebase Realtime Database, com login anônimo. As regras de segurança estão em `firebase-regras.json`.
